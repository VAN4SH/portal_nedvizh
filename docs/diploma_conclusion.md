# Заключение

Выпускная квалификационная работа была посвящена проектированию и разработке веб-портала для продажи и аренды недвижимости, что является актуальной задачей в условиях активного развития цифровых сервисов, электронной коммерции и онлайн-площадок для взаимодействия продавцов, покупателей, арендаторов и представителей бизнеса. Современный рынок недвижимости требует удобных, быстрых и доступных информационных систем, позволяющих пользователям получать сведения об объектах, сравнивать предложения, публиковать объявления и оперативно связываться с авторами размещенных материалов.

Целью данной работы являлась разработка функционального, масштабируемого и удобного веб-портала для продажи и аренды недвижимости, отвечающего современным требованиям пользователей и бизнеса. В ходе выполнения работы последовательно решались задачи, обеспечивающие достижение поставленной цели:

- проведен анализ предметной области, связанной с цифровыми сервисами для рынка недвижимости, рассмотрены потребности основных участников: покупателей, арендаторов, продавцов, собственников и агентов;
- исследованы существующие аналогичные решения, что позволило определить востребованные функции веб-порталов недвижимости, выявить типовые пользовательские сценарии и возможные направления улучшения;
- сформулированы функциональные и нефункциональные требования к разрабатываемой системе, включая требования к удобству интерфейса, надежности хранения данных, безопасности пользовательских учетных записей и расширяемости проекта;
- выполнен выбор технологического стека, включающего язык программирования Python, микрофреймворк Flask, Flask-SQLAlchemy, Flask-Login, базу данных SQLite, шаблонизатор Jinja2, HTML, CSS, JavaScript и Bootstrap;
- проведено проектирование веб-приложения, включающее построение UML-диаграмм, определение основных сущностей системы, проектирование структуры базы данных и пользовательских сценариев;
- реализованы ключевые модули веб-портала: регистрация и авторизация пользователей, каталог объявлений, фильтрация объектов недвижимости, просмотр карточки объекта, личный кабинет, добавление, редактирование и удаление объявлений;
- выполнена проверка работоспособности основных функций приложения и определены направления дальнейшего развития проекта.

Теоретическая часть работы раскрывает особенности создания веб-ориентированных информационных систем для коммерческого сектора. В ней рассмотрены основные этапы разработки программного обеспечения: анализ предметной области, формирование требований, выбор технологий, проектирование архитектуры, реализация и тестирование. Особое внимание уделено специфике веб-порталов недвижимости, поскольку такие системы должны одновременно обеспечивать удобный поиск информации, надежную работу с пользовательскими данными и понятный интерфейс для разных категорий пользователей.

В ходе исследования были рассмотрены подходы к построению современных веб-приложений, принципы организации клиент-серверного взаимодействия, особенности использования шаблонов страниц, хранения данных и обеспечения доступа к защищенным разделам. Это позволило обосновать выбор архитектуры приложения и определить набор инструментов, достаточный для реализации учебного, но функционально завершенного веб-портала.

В значительной степени внимание было уделено вопросам проектирования структуры приложения и объектно-ориентированного моделирования. Были разработаны диаграмма вариантов использования, диаграммы состояний, диаграмма классов и диаграмма пакетов. Диаграмма вариантов использования позволила описать взаимодействие гостей, зарегистрированных пользователей и продавцов с системой. Диаграммы состояний отразили процессы авторизации пользователя и жизненный цикл объявления о недвижимости. Диаграмма классов показала ключевые сущности приложения, такие как пользователь и объявление, а диаграмма пакетов отразила логическую организацию проекта.

Разработанная модель данных включает две основные сущности: пользователя и объявление. Пользователь хранит учетные и контактные сведения, а также статус агента по недвижимости. Объявление содержит описание объекта, цену, тип недвижимости, характеристики помещения, город, адрес, изображения и ссылку на автора. Между пользователями и объявлениями установлена связь «один ко многим», что соответствует предметной области: один пользователь может разместить несколько объявлений, но каждое объявление принадлежит конкретному автору.

Практическая часть работы была направлена на непосредственную реализацию веб-приложения. Серверная логика выполнена на языке Python с использованием Flask. Для работы с базой данных применен Flask-SQLAlchemy, позволяющий описывать таблицы через Python-классы и выполнять операции с данными через объектную модель. Для управления пользовательскими сессиями использован Flask-Login. Пользовательский интерфейс построен на основе HTML-шаблонов Jinja2, CSS, JavaScript и Bootstrap, что позволило создать адаптивные страницы с единой структурой и современным визуальным оформлением.

Результатом проведенной разработки стало создание веб-портала «Недвижимость Pro», предоставляющего пользователям основные возможности для работы с объявлениями о недвижимости. Посетители сайта могут просматривать главную страницу, переходить в каталог, фильтровать объявления по типу объекта, городу и диапазону цены, а также открывать подробные карточки недвижимости. Зарегистрированные пользователи получают доступ к личному кабинету, могут редактировать профиль, добавлять собственные объявления, изменять сведения о них и удалять устаревшие записи.

Разработанное приложение демонстрирует полный цикл работы веб-сервиса: от регистрации пользователя до публикации и последующего управления объявлением. В системе реализованы базовые механизмы безопасности, включая хэширование паролей, защиту отдельных маршрутов авторизацией и проверку владельца объявления перед редактированием или удалением. Это повышает надежность приложения и предотвращает несанкционированное изменение данных другими пользователями.

Практическая значимость работы заключается в возможности использования разработанного веб-портала как основы для дальнейшего развития полноценной информационной системы в сфере недвижимости. Проект может применяться в учебных целях для демонстрации принципов разработки веб-приложений, работы с базой данных, организации авторизации и построения пользовательского интерфейса. Кроме того, реализованная система может быть расширена и адаптирована под реальные задачи агентства недвижимости, частной доски объявлений или локального сервиса для публикации объектов аренды и продажи.

К возможным направлениям дальнейшего развития проекта можно отнести добавление административной панели, модерации объявлений, системы избранного, полноценного обмена сообщениями между пользователями, карты объектов недвижимости, сортировки и расширенного поиска, уведомлений, интеграции с почтовыми сервисами, а также переход на более производительную серверную СУБД, например PostgreSQL. Также перспективным направлением является улучшение пользовательского интерфейса и добавление инструментов аналитики для продавцов и агентов.

В целом, выполненная работа позволяет сделать вывод о целесообразности применения современных веб-технологий и принципов объектно-ориентированного проектирования при создании информационных систем для коммерческого сектора. Реализация поставленных задач позволила закрепить теоретические знания в области анализа, проектирования и разработки веб-приложений, а также получить практический результат в виде работающего портала для продажи и аренды недвижимости. Разработанное приложение отвечает основной цели дипломной работы и может служить основой для дальнейшего совершенствования и внедрения в прикладную деятельность.
